# TKT-2024-004 — HKEX file contains unknown client code

| Field | Value |
| --- | --- |
| Ticket ID | TKT-2024-004 |
| Summary | HKEX venue file references unregistered client code ACME-209; affected rows moved to reject report |
| Severity | MEDIUM |
| Status | CLOSED |
| Related Module | Trade Importer |
| Opened At | 2024-02-27T00:15:00 |

## Symptom

Import batch `IMP-20240227-HKEX` rejected 6 records referencing client code
`ACME-209`, which does not exist in `clients`.

## Expected Behavior

All records in the venue file map to registered clients and load into
`trades`.

## Actual Behavior

The 6 records were written to the reject report; the rest of the batch
loaded normally and the HKEX margin run completed without them.

## Investigation Notes

- Client registration for ACME-209 was pending in onboarding; the venue had
  been notified of the code ahead of ACFS registration.
- Client was registered on 2024-02-27 and the quarantined records were
  reprocessed for the next business date.

- Runbook: `rb-failed-trade-import.md`
