# TKT-2024-003 — ASX trade file rejected on duplicate trade IDs

| Field | Value |
| --- | --- |
| Ticket ID | TKT-2024-003 |
| Summary | ASX venue file for batch IMP-20240312-ASX rejected due to duplicate trade IDs; margin run blocked |
| Severity | HIGH |
| Status | RESOLVED |
| Related Module | Trade Importer |
| Opened At | 2024-03-12T23:47:00 |

## Symptom

`trade_import` for batch `IMP-20240312-ASX` failed with a non-zero exit
code; the reject report lists 14 records whose `trade_id` already exists in
`trades`. The ASX margin run was blocked.

## Expected Behavior

The venue file loads into `trades` without rejects and the nightly window
continues to the ASX margin run.

## Actual Behavior

Import stopped at validation; downstream jobs for ASX did not start.

## Investigation Notes

- ASX confirmed the file was a resend after their earlier partial delivery.
- Duplicated rows were confirmed as a venue resend and quarantined under the
  failed-trade-import exception; the batch was reprocessed, then
  `position_maintenance`, `margin_run`, `reconciliation`, and `invoicing`
  were restarted in order after checking each `batch_jobs` status.
- Window recovered at 04:10 on 2024-03-13 after invoicing completed.
