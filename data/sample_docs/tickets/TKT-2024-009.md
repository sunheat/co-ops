# TKT-2024-009 — HKEX margin run failed on missing previous close

| Field | Value |
| --- | --- |
| Ticket ID | TKT-2024-009 |
| Summary | Margin run MR-20240314-HKEX failed because newly listed instruments had no previous close |
| Severity | HIGH |
| Status | RESOLVED |
| Related Module | Margin Service |
| Opened At | 2024-03-14T02:22:00 |

## Symptom

`margin_run` for HKEX on business date 2024-03-14 failed; `margin_runs`
row `MR-20240314-HKEX` shows status `FAILED`.

## Expected Behavior

The run completes for all HKEX positions and writes `margin_results`.

## Actual Behavior

Variation margin calculation failed for positions in two newly listed
instruments whose `previous_close` was absent in `positions`.

## Investigation Notes

- Root cause: position maintenance does not seed `previous_close` for new
  listings.
- Fix applied: seed `previous_close` with the listing-day close, mark the
  run `FAILED`, and rerun per the batch-job-failure runbook.
- Rerun `MR-20240314-HKEX` completed at 03:40; reconciliation followed.
