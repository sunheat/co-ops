# TKT-2024-009 — HKEX position load failed on missing previous close

| Field | Value |
| --- | --- |
| Ticket ID | TKT-2024-009 |
| Summary | Margin run MR-20240314-HKEX failed because newly listed instruments had no previous close |
| Severity | HIGH |
| Status | RESOLVED |
| Related Module | Margin Service |
| Opened At | 2024-03-14T02:22:00 |

## Symptom

`margin_run` for HKEX on business date 2024-03-14 failed; `margin_runs`
row `MR-20240314-HKEX` shows status `FAILED`. Position maintenance rejected
two newly listed instruments before their rows could be inserted because
`previous_close` was missing.

## Expected Behavior

The run completes for all HKEX positions and writes `margin_results`.

## Actual Behavior

Position maintenance could not insert the two new-instrument rows because
`positions.previous_close` is `NOT NULL`; no malformed row was stored and
`MarginCalculator` did not read a null value. The margin run failed with
incomplete position inputs.

## Investigation Notes

- Root cause: position maintenance did not seed `previous_close` before
  inserting rows for new listings.
- Fix applied: seed `previous_close` with the listing-day close, reload and
  verify the position rows, mark the run `FAILED`, and rerun per the
  batch-job-failure runbook.
- Rerun `MR-20240314-HKEX` completed at 03:40; reconciliation followed.
