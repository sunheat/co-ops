# INC-2024-001 — SGX venue file format change blocked morning reporting

| Field | Value |
| --- | --- |
| Incident ID | INC-2024-001 |
| Date | 2024-01-09 |
| Severity | HIGH |
| Affected Modules | Trade Importer, Batch Scheduler |
| Status | CLOSED |

## Timeline

- 01:00 — `trade_import` for `IMP-20240109-SGX` failed; the venue file
  contained a new trailing column the importer did not expect.
- 01:20 — Ticket raised; the whole file was rejected, so no trades loaded.
- 02:40 — Importer tolerance for trailing columns hotfixed and the batch
  reprocessed.
- 04:10 — Margin run and reconciliation recovered; morning reporting
  delayed by approximately three hours.
- 04:25 — The Invoice Generator completed after reconciliation, and the
  downstream batch window was recovered.

## Impact

No trades were available for the SGX margin run until recovery; venues were
notified of the reporting delay.

## Root Cause

The importer validated the file against a fixed column layout with no
version detection, so an additive format change rejected the entire file.

## Resolution and Follow-ups

- Importer updated to tolerate additive trailing columns and to record the
  detected format version per batch.
- Reject report review added to the failed-trade-import runbook.
