# INC-2024-004 — Duplicate invoices during January rerun

| Field | Value |
| --- | --- |
| Incident ID | INC-2024-004 |
| Date | 2024-02-26 |
| Severity | MEDIUM |
| Affected Modules | Invoice Generator |
| Status | CLOSED |

## Timeline

- 2024-02-26 — The Invoice Generator was rerun for period 2024-01 after a
  margin correction.
- 2024-02-26 — The rerun issued fresh invoices instead of replacing the
  originals, creating duplicate `invoices` rows for 11 clients.
- 2024-02-27 — Duplicates were cancelled before any client received them.

## Impact

No client was billed twice; support spent one day reconciling invoice
statuses.

## Root Cause

The generator had no rerun guard: it did not check for existing invoices
for the same client and period before issuing.

## Resolution and Follow-ups

- The generator now detects existing invoices for a client-period and
  cancels and reissues instead of duplicating.
- The invoice-discrepancy runbook notes reruns as a cause of double
  counting when tracing disputed lines.
