# INC-2024-003 — Untracked manual position adjustment caused multi-day breaks

| Field | Value |

| Severity | HIGH |
| Affected Modules | Position Reconciler |
| Status | CLOSED |

## Timeline

- 2024-02-14 — A manual position adjustment was applied for a client on
  SGX without an audit trail entry.
- 2024-02-15, 2024-02-16, and 2024-02-19 — Reconciliation raised the same
  break on three consecutive business dates; each was triaged independently.
- 2024-02-19 — The breaks were linked to the single adjustment; the venue
  submission was corrected and reconciliation cleared.

## Impact

Three days of repeated break triage and a late venue submission for the
affected instrument.

## Root Cause

The standard adjustment workflow had a break-glass path that was exempt from
the audit requirement, so the connection between the adjustment and the
recurring breaks was not visible to the triaging engineers.

## Resolution and Follow-ups

- The standard adjustment path now requires an audit trail entry before it can
  be saved; the break-glass path was identified as an exception and is being
  brought under the same check.
- The reconciliation-break runbook now instructs engineers to check recent
  adjustments when the same instrument breaks on consecutive dates.
